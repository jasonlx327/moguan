# 中国政府网商务部政策发现链

本目录保存墨观从中国政府网政策文件库发现的商务部政策候选。

## 接口性质

- 检索入口位于中国政府网官方域名，公开、无需认证。
- 接口返回标题、文号、发布机关、发布日期、摘要和原文链接。
- 机器接口契约未见正式公开文档，因此稳定性等级低于 EU Cellar。
- 中国政府网索引用于发现，最终事实必须回到商务部或中国政府网官方原文复核。

## 事实边界

- 商务部公告或部令可能构成正式措施。
- 新闻发言人回应、政策解读和会谈消息属于官方立场或背景，不等于新法律措施。
- “两用物项”或“供应链”命中不自动等于半导体事件。
- 未完成人工复核的记录不得进入事件账本或推演流程。

## 当前状态

2026-07-28 本地运行环境连接 `sousuo.www.gov.cn`、`www.mofcom.gov.cn`
和 `exportcontrol.mofcom.gov.cn` 时，TLS 连接在获得响应前被关闭。curl、
Node fetch、应用内浏览器和隔离安装的 Crawl4AI 0.9.2 均得到相同结果。
Crawl4AI 能正常读取对照页 `example.com`，但三个政务入口均返回
`net::ERR_CONNECTION_CLOSED` 和零字节HTML，因此问题发生在页面解析之前。

适配器及契约测试已经完成，但没有用搜索引擎结果或第三方镜像替代本次官方接口
快照。`current.json` 因此明确保存为 `blocked`。完整探针结果见
`crawl4ai-probe-2026-07-28.json`。

## 使用

```bash
npm run cn-policy:fetch
npm run cn-policy:validate
```

默认查询截至运行日的连续 30 个自然日，发布机构限定为商务部，关键词为：
`半导体`、`芯片`、`出口管制`、`先进计算`、`两用物项`。

## GitHub Actions 远程探针

`.github/workflows/cn-policy-official-probe.yml` 提供一个透明的外部运行方式：

- 每日北京时间 07:35 运行，也可手动触发；
- 仓库权限仅为 `contents: read`；
- 不配置密钥、Cookie、代理、登录或第三方数据源；
- 成功和失败都会生成JSON证据文件及其 `.sha256` 校验文件，保存14天；
- 成功文件包含每次官方接口响应的SHA-256，旁路校验文件记录完整快照SHA-256；
- 失败文件明确标记 `blocked`，工作流同时失败，不把失败当作无事件；
- 工作流只生成Artifact，不自动覆盖仓库中的 `current.json`。
