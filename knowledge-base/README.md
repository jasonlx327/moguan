# 墨观知识库

**版本：v0.1｜状态：P0 最小跨时代知识链已达到 P1 入口**

本目录是新版墨观的古籍与现代校验知识库，不存放每日新闻全文。每日事件保留在事件层；只有事实稳定后，系统才依据事件主题检索这里的材料。

- 已建立作品、来源、段落、事件映射、解释和规则六类注册表；
- 已建立跨时代 P0 清单与自动校验脚本；
- 已围绕观察方法、传统天文、疫情、气候异常与航运阻滞登记 17 部作品、21 个来源、40 条核对段落；
- 已建立 3 条事件映射，均明确现代证据优先；
- 已按五层解释结构完成 3 条事件解释样例；
- 已核对段落：40；
- 可公开引用段落：3；
- 可参与规则段落：0；
- 可执行规则：0。

“骨架搭建完成”不等于“知识库内容完成”。旧项目中的材料不会自动取得新版资格。

40 条记录达到 P0 设定的 30—50 条最小样本门槛，但不代表古籍全文库已经完成。新增记录均保持 `publishable: false`、`rule_eligible: false`；它们可供内部检索和审核，不能越级作为公开引文或自动推演规则。

## 目录

- `schemas/`：统一字段契约；
- `registries/`：作品、来源、段落、事件映射、解释和规则注册表；
- `manifests/`：P0 建设目标与实际计数；
- `scripts/validate-knowledge-base.mjs`：引用门槛与交叉引用校验。

注册表允许按 `sources.*.json`、`works.*.json`、`passages.*.json` 分片扩充；校验器会合并所有分片并检查重复编号、来源锚点、时代层级和 P1 数量门槛。

## 检索

```bash
npm run kb:search -- "水运 仪象"
npm run kb:search -- "二十八宿" --layer observation_refinement
```

检索结果只返回已登记材料及其审核状态。检索命中不等于允许公开引用，更不等于获得规则资格。

## 三道门

1. `needs_revalidation` 和 `pending_review` 只能用于内部整理；
2. `public_citation` 才能出现在用户可见的古籍引文中；
3. `rule_eligible` 还必须保留允许用途、禁止外推和反证，才能支持解释规则。

古籍材料只提供历史解释框架，不修改现代事实判断，也不作为现代未来结果的独立证据。

公开引用还必须满足：固定主来源、第二文本见证、释义复核、边界复核。通过公开引用不等于取得规则资格。

## 首批映射边界

- 疫情：只讨论公共照护与灾疫救济，不作天谴解释，不提供医疗建议；
- 厄尔尼诺：可讨论时序、过度与不足，但《答潘子善》证明天气与五行配属并非唯一共识，因此暂不分配固定五行；
- 霍尔木兹：只讨论聚货、交易与流通，通航状态仍完全由现代航运、港口和新闻证据判断。
