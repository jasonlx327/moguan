# 墨观事件日度候验器

当前候验器只服务 `EVENT-2026-07-29-01`，不承担通用新闻抓取。

它每天检查：

1. 商务部已确认答记者问是否仍可访问；
2. 商务部安全与管制局公开索引是否出现新的相关链接；
3. VIGO Photonics 第35/2026号报告是否仍可访问；
4. VIGO投资者关系公告索引是否出现新的中国出口限制、许可证或影响报告。

商务部子站不可访问时，候验器会依次尝试商务部主站上的同一篇官方答记者问和新闻发布索引，并记录是否启用了备用入口。

运行：

```bash
npm run event:watch
```

默认生成 `event-watch/daily/YYYY-MM-DD.json` 与对应的 SHA-256 文件。同一日期的记录不可覆盖。

结果边界：

- `no_new_evidence`：两个索引都完成检查，未发现超出当前账本的新相关链接；
- `new_evidence_candidates`：发现候选链接，但尚未核验，不能自动改变事实或解释；
- `not_determined`：至少一个索引未完成，不能声称“暂无新增”；
- 候验器不生成预测，不将关键词匹配直接升级为事实。
