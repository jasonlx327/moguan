# 墨观知识库分期框架

**版本：v0.1｜范围：先秦至两宋**

## 一、范围决定

墨观知识库不再以公元 220 年为统一截止线，正式扩展到宋代结束。扩展的目的不是把更多术数材料堆入系统，而是补齐中国古代天文学从理论源头、制度集成到观测精化的发展链。

## 二、四层结构

### A｜理论源头层：先秦—两汉

保存天人关系、阴阳五行、八卦、时序、早期星官和主要反证传统。该层回答“概念从哪里来”，不垄断后世解释，也不因为年代早而拥有更高事实权重。

首批候选：《易传》《尚书·洪范》《吕氏春秋》《淮南子》《史记·天官书》《论衡》。

### B｜制度集成层：魏晋—隋唐

保存天文志、占候分类、历法制度、文献汇编和跨文化吸收。该层回答“知识如何被整理、制度化和重新解释”。

首批候选：《晋书·天文志》《隋书·天文志》《乙巳占》《开元占经》《大衍历》相关材料，以及来源可追溯的七曜、宿曜文献。

### C｜观测精化层：两宋

保存星图、客星和彗星记录、历法修订、仪器结构、观测方法及官署制度。该层回答“古人实际看到了什么、如何记录和测量”。

首批候选：《新仪象法要》、宋代星图与客星记录、《梦溪笔谈》天文历法条目、《宋史·天文志》中可追溯至宋代原始记录的材料。

### D｜现代校验层

保存现代星历、天文学史研究、文本校勘与版本说明。该层用于校正日期、天体身份、文本年代和事实边界，不替古代观点提供现代科学背书。

## 三、每条材料的强制字段

- `historical_layer`：理论源头／制度集成／观测精化／现代校验；
- `source_function`：理论／占候／观测／历法／仪器／制度／史例／评论；
- `event_date`：被记录现象的发生时间；
- `record_date`：原始记录形成时间；
- `compilation_date`：现存作品编纂时间；
- `edition_date`：当前使用底本年代；
- `cultural_lineage`：本土／印度／中亚／混合／待考；
- `source_text`：原文；
- `modern_paraphrase`：现代释义；
- `allowed_use`：允许参与的分析环节；
- `forbidden_inference`：禁止外推；
- `counterevidence`：异说、反证与现代辨析；
- `review_status`：待录入／待校核／已校核／可公开引用／可参与规则。

## 四、调用原则

1. 先调用观测与现代校验材料确认“看到了什么”，再调用思想或占候材料说明“古人如何理解”；
2. 不把《宋史》的元代编纂时间隐去，也不把其中所有记录直接视作宋代原始记录；
3. 不把唐代吸收的印度、中亚星学包装成纯粹本土传统；
4. 不把宋代仪器精度转化为占候结论的可信度；
5. 同一现象存在多个时代解释时并列呈现，不自动融合成单一答案；
6. 任何可执行规则都必须保留历史层级和材料功能，不能脱离原始语境。

## 五、P0 准入范围

P0 不追求全库完成，只建立一条跨时代的可审计示范链：

1. 一条先秦—两汉理论或反证材料；
2. 一条唐代文献集成或历法材料；
3. 一条宋代观测、星图或仪器材料；
4. 一条现代校验材料；
5. 同一事件页面分别展示四层材料的用途与边界。
