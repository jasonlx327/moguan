# 墨观解释结构 v0.1

**状态：首批可执行版本**  
**适用对象：经过事实核验、完成原典公开引用审核的公共事件**

## 一、为什么需要独立的“墨观解释”

事实、古籍和预测不能混写。

- 事实回答“发生了什么”；
- 原典回答“古人曾如何描述某种结构”；
- 墨观解释回答“这个古典概念为什么可以帮助我们理解当前事件”；
- 情景推演回答“接下来可能出现哪些可检验路径”。

墨观解释是一座桥，不是事实来源，也不是神秘结论。它必须允许读者看见桥从哪里搭起、在哪里断开。

## 二、五层解释结构

### 第一层｜现实之变

只从已经核验的事实中提取结构性变化，不增加新事实。

回答：

- 什么正在变化；
- 变化作用于哪些关系；
- 哪些部分已经确认；
- 哪些部分仍然未知。

### 第二层｜古典之言

展示已经通过公开引用审核的原典、篇章、时代和现代释义。

回答：

- 古人使用了什么概念；
- 原文在其自身时代语境中是什么意思；
- 这条材料主要是理论、制度、史例、观测还是评论。

### 第三层｜古今之桥

说明现代事件特征和古典概念共享的“关系结构”，而不是宣称两者存在科学因果。

允许使用的结构包括：

- 显与隐；
- 动与静；
- 聚与散；
- 通与阻；
- 生长与收敛；
- 承载与失衡；
- 时序、过度与不足；
- 局部变化向系统后果的传导。

必须明确写出：

- 现实特征；
- 古典概念；
- 二者共享的结构；
- 为什么这只是解释性类比。

### 第四层｜边界与异说

主动说明解释在哪里失效。

至少包含：

- 不能由原典推出的现代结论；
- 传统内部的异说；
- 可能成立的反向解释；
- 尚未解释的部分；
- 是否存在跨时代距离过大的问题。

没有这一层，内容只能称为古典修辞，不能称为墨观解释。

### 第五层｜继续观察

把解释重新交还给现实世界。

只列：

- 后续观察窗口；
- 能支持当前解释的现实信号；
- 会削弱或推翻当前解释的信号；
- 解释需要重新审核的条件。

这一层不自动生成预测概率。需要形成预测时，必须进入独立的情景推演与验期账本。

## 三、页面表达顺序

用户可见顺序固定为：

> 事实摘要 → 原典与释义 → 墨观解释 → 边界与异说 → 后续观察 → 独立情景推演

不得把“吉凶”“五行结论”放在事实之前，也不得用古典术语替代具体事实。

## 四、五行与八卦的进入条件

五行或八卦不是每项事件的必填项。只有同时满足以下条件时才可以进入公开解释：

1. 现实事件存在明确的功能或关系特征；
2. 至少一条已取得规则资格的原典支持该映射；
3. 传统内部异说已经登记；
4. 映射不是对国家、行业、疾病或人群的永久归类；
5. 页面能同时展示权重理由、反向解释与禁止外推。

当前首批三项事件没有任何一项满足全部条件，因此均不输出五行或八卦结论。

## 五、映射类型与依据

不使用“低／中／高”判断映射。每项映射必须公开它属于哪种关系，以及为何允许使用：

- **直接历史参照**：讨论对象和制度语境具有明确历史连续性；
- **结构类比**：古今机制不同，但共享可说明的功能或关系结构；
- **争议映射**：传统内部存在重要异说，必须并列展示；
- **禁止映射**：主要依赖牵强比喻、永久五行归类或以古代因果替代现代事实。

映射类型只说明知识库如何参与解释，不能改变现代事实，也不输出推演置信度。

## 七、发布门槛

一项墨观解释只有同时满足以下条件才能公开：

- 事件事实版本已经冻结；
- 引用段落取得 `public_citation`；
- 古今映射和禁止外推已经填写；
- 至少一条反向解释或限制已经登记；
- 映射类型与知识库依据有文字理由；
- 后续观察信号可被现实来源验证；
- 解释与预测存储在不同对象中；
- 发布后保留版本与修订记录。

## 八、写作原则

- 使用清楚的现代中文，古典术语必须解释；
- 不模仿谶语、占辞或故作玄奥的语气；
- 不写“古人早已预测了今天”；
- 不写“天象导致战争、市场或疫情”；
- 不把类比写成证明；
- 不用流畅文字掩盖未知事项；
- 宁可承认暂时不能映射，也不补齐一个看似完整的体系。
