# 墨观开放数据源宪章与首批登记表

**版本：v0.1**  
**日期：2026 年 7 月 28 日**  
**状态：现行数据源准入规范**

## 一、基本立场

墨观只把公众能够合法取得、来源能够公开说明、第三方能够重复验证的数据作为核心事实输入。

> 墨观不以占有数据制造门槛，而以发现、整理、连接、解释和候验公开信息创造价值。

开放不等于免费展示页面，也不等于可以任意抓取和再分发。每个来源必须分别审查：

1. 公众是否能够访问；
2. 是否提供机器可读入口；
3. 是否要求免费注册或密钥；
4. 是否允许缓存、加工和重新发布；
5. 是否能够保存原始链接和版本；
6. 是否存在稳定的更新时间或修订记录。

## 二、开放等级

| 等级 | 定义 | 核心事实层是否可依赖 |
|---|---|---|
| O0 | 无账户、无密钥即可合法访问的官方网页、文件、RSS、API或下载包 | 可以 |
| O1 | 公众可以免费注册并取得密钥或账户，获取方式可复现 | 可以，但必须有O0降级路径或明确显示中断 |
| O2 | 内容可公开查看，但批量访问、缓存或再分发条款不明确或受限制 | 只保存必要事实和原始链接，等待许可审查 |
| O3 | 付费订阅、商业授权、封闭接口或仅合作伙伴可用 | 不作为墨观核心依赖 |
| X | 绕过登录、付费墙、访问控制或技术限制才能取得 | 禁止 |

墨观的公开代码必须能够在不配置O3来源的情况下完成基本的观象、纪事、察势、稽古、通变和候验闭环。

## 三、来源优先级

同一事实存在多个来源时，按下列顺序处理：

1. 法律、法规、行政命令、政府公报和正式数据库；
2. 政府部门、国际组织和监管机构正式公告；
3. 企业公告、交易所披露和经审计报告；
4. 科研机构、大学和公开科学数据库；
5. 通讯社和专业媒体原始报道；
6. 其他媒体、研究者和公开社区线索。

低优先级来源可以帮助发现事件，但不能覆盖高优先级来源已经确认的事实。

## 五、采集与保存原则

### 必须

- 优先使用API、RSS、Atom、CSV、XML和官方批量下载；
- HTML采集只提取必要的标题、机构、日期、文号、正文事实和原始链接；
- 保存抓取时间、内容代表时间、时区和原始文件哈希；
- 原始页面发生变化时新增版本，不静默覆盖；
- 区分“未更新”“访问失败”“格式变化”“来源撤回”和“确无事件”；
- 对PDF保存原文件标识、页码和提取方法；
- 对免费密钥设置配额、到期和降级提示；
- 允许任何人根据公开适配器重新取得相同类型的数据。

### 禁止

- 绕过登录、验证码、付费墙、robots限制或访问控制；
- 把搜索引擎摘要当作原始事实；
- 把商业聚合器缓存当作自有原始数据；
- 没有许可依据就批量公开新闻全文、图片或数据库镜像；
- 来源失效后用模型补造字段；
- 因为接口返回空数组就宣布现实中没有事件。

### 开源采集器与 AI 爬虫

墨观允许使用开源爬虫、浏览器自动化和 AI 抽取项目作为可替换的采集插件，但它们不构成事实来源，也不能改变来源开放等级。

采集插件必须：

- 许可证允许墨观的开源使用方式，并保存项目版本与许可证；
- 遵守目标网站的服务条款、robots规则、频率限制和访问控制；
- 保存官方原始链接、抓取时间、原始响应哈希与解析器版本；
- 允许关闭大模型，只用确定性规则重新提取核心字段；
- 将模型抽取字段标记为待复核，不覆盖文号、日期、机构等原始字段；
- 页面结构变化或抽取结果异常时失败并报警，不静默生成“合理”内容。

2026-07-28 的首轮候选：

| 项目 | 许可证 | 建议角色 | 当前判断 |
|---|---|---|---|
| `unclecode/crawl4ai` | Apache-2.0 | 动态页面读取、正文与Markdown抽取、页面适配 | 首选实验采集器；接入前仍需做最小安全与可复现性测试 |
| `microsoft/playwright` | Apache-2.0 | 浏览器渲染、网络与DOM诊断、确定性页面测试 | 作为底层浏览器工具，不负责事实判断 |
| `ScrapeGraphAI/Scrapegraph-ai` | MIT | 非规则化页面的实验性结构抽取 | 只进入实验区，AI输出不得直接进入事件账本 |
| `firecrawl/firecrawl` | AGPL-3.0 | 自托管抓取与变更检测参考 | 许可证对服务端衍生使用影响较大，暂不作为默认依赖 |

## 六、失效与退出机制

数据源出现下列情况之一时必须降级：

- 连续三次计划采集失败；
- 页面结构或接口契约发生未适配变化；
- 数据超过约定新鲜度；
- 许可或服务条款发生变化；
- 来源撤回、停止维护或被确认存在系统性错误；
- 需要升级为付费服务才能继续取得核心字段。

降级后保留历史记录，标记最后成功时间，暂停由该来源产生新事实，启用已登记的替代来源，并且不得把替代来源伪装成原来源的连续更新。

首批完整数据源验证围绕：

> **全球半导体出口管制与AI芯片供应链重组**

这不是为了建立一个半导体资讯栏目，而是验证墨观能否从中、美、欧公开一手材料中形成同一事件的法律版本、政策回应、企业影响和后续候验。

## 九、P0接入顺序

### 第一批：无需账户的正式事实

1. FederalRegister.gov无密钥API与GovInfo官方文件；
2. EU Cellar REST与SPARQL；
3. 工信部RSS；
4. 商务部正式公告；
5. BIS和荷兰政府新闻页的最小HTML监测。

### 第二批：免费注册与统计验证

1. UN Comtrade；
2. WTO可下载数据；
3. 企业正式公告和交易所披露；
4. 需要免费密钥的其他公共统计接口。

### 暂不接入

- WorldMonitor Pro接口；
- 商业供应链图谱；
- 商业船舶、航班或企业关系数据库；
- 需要绕过访问控制的新闻和社交平台；
- 来源、许可和更新时间无法说明的数据包。

## 十、P0成功标准

首个数据源闭环完成时，应能自动或半自动回答：

1. 过去三十日中美欧分别发布了哪些正式政策文件？
2. 每份文件何时发布、何时生效、是否修订？
3. 涉及哪些产品、技术、主体、地域与许可状态？
4. 哪些内容是法律事实，哪些只是机构解释或公开回应？
5. 哪些贸易和产业数据能够验证现实影响，延迟多久？
6. 哪些来源目前缺失、受限或等待人工审核？

只有能够回答以上问题，数据源才真正进入墨观，而不是只在界面上增加一个图层或新闻列表。
