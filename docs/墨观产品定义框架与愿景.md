# 墨观

## 产品定义、总体框架与长期愿景

**版本：产品蓝图 v0.2｜基于产品设定 v0.5**  
**日期：2026 年 7 月 23 日**

> 从中国古代星空出发，结合真实天象、地球天气与公共事件，用先秦至宋代的分层文献体系分析世界如何变化。

---

# 一、愿景

墨观希望建立一种源自中国、面向世界的数字世界观：让任何人都能从天空进入地球，在真实数据和公共事实之上，理解时间、秩序、消长与转变。

它不要求用户相信神秘力量，也不把古代观念包装成现代科学。墨观要做的是把中国古人观察天地、四时与人事的方式，转化为一套可阅读、可追溯、可讨论、可反驳、可复盘的当代产品。

长期来看，墨观希望成为：

- 面向公众的中国古典世界分析入口；
- 连接真实天文、地球天气、世界事件与中国思想的数字基础设施；
- 一座可检索、可校勘、可引用的先秦至宋代古代天文与思想知识库；
- 一套公开记录预测、错误和修订过程的长期观察系统；
- 能够被全球用户理解的中国文化科技产品。

**愿景表达**

> 让人们不只是知道世界发生了什么，也能从中国古典思想中获得一种理解变化的方法。

# 二、产品定义

墨观不是传统新闻媒体，不是纯粹的天文或天气应用，也不是命理与占卜工具。

墨观是一套面向公众的“古典世界分析产品”：先用现代数据确认天空、天气和事件事实，再调用先秦至宋代、经过时代与功能分层的中国文献解释其结构与变化，最后形成能够被未来事实检验的情景推演。

## 核心用户价值

用户在同一条体验中完成六件事：

1. 看见当天真实的日月五星与中国传统星空；
2. 观察地球天气、自然条件和事件所在区域；
3. 掌握少量真正重要、来源可核验的世界事件；
4. 阅读与事件有关的先秦至宋代原典、时代脉络和现代释义；
5. 理解阴阳、五行、八卦与时序所描述的关系变化；
6. 追踪一项有期限、有条件、可结算的情景预测。

## 产品的根本差异

- 新闻回答“发生了什么”，墨观进一步讨论“它处在怎样的变化结构中”；
- 天文软件展示现代天体位置，墨观叠加中国传统星空及其历史语境；
- 古籍数据库提供文本，墨观建立从原文到现代事件分析的可审计链；
- 预测产品追求结论，墨观同时公开支持证据、反向证据、失效条件和到期结果；
- 命理产品面向个人吉凶，墨观只分析公共世界，不采集个人命盘。

## 产品入口层级

墨观的主入口始终是“今日天地”，而不是“提交一件事”。首页先呈现当日真实星象、历法、全球天气和重要公共事件，让用户从共同的天地与现实背景进入产品。

截图、文字和链接作为二级“事件研判”入口存在。它的作用是让用户选择一个观察焦点，并把该事件纳入当日时空、现实证据和古典分析框架；它不是起卦、问事或替用户判断个人成败的工具。

> 主入口回答“今天的天地与世界处于什么状态”；事件研判回答“这件公共事件在当前天地与现实环境中，应当如何理解和继续观察”。

# 三、产品世界模型

墨观的主路径是：

> 仰观天象 → 俯察地理 → 观察人事 → 引证古籍 → 分析变化 → 提出情景 → 到期复盘

这不是装饰性的页面顺序，而是产品判断的先后约束：先事实，后解释；先解释，后预测。

## 五个产品模块

| 模块 | 用户看到什么 | 核心任务 |
|---|---|---|
| 墨观·天时 | 真实日月五星、月相、节气、干支、三垣与二十八宿 | 以现代星历确认天空事实，以中国星空提供文化坐标 |
| 墨观·地气 | 云层、风场、温度、降水、昼夜线与异常天气 | 呈现公共事件所处的真实自然背景 |
| 墨观·人事 | 每日少量重要事件、时间、地点、来源和未知事项 | 从信息噪音中形成可核验的世界事件层 |
| 墨观·象理 | 原典、释义、阴阳、五行、八卦和变化分析 | 说明古典概念如何映射到现代事件，并展示异说与反证 |
| 墨观·验期 | 情景、触发条件、失效条件、截止时间与结算结果 | 把预测从模糊叙事变成可复盘记录 |

## 从首页到结论的体验

### 1. 今日天地

首屏从当日星象开始，呈现用户所在地或全球视角下的真实天空。用户可以切换现代天文坐标与中国传统星空图层，并在时间轴上查看天体关系变化。首页同时汇总当日历法、全球天气和少量重要公共事件，但不把事件输入框置于视觉中心。

### 2. 地气

镜头从天穹下降到地球，显示当日云层、风、温度或降水，并标出公共事件所在区域。天气没有现实关联时，产品必须明确说明“未发现直接影响”。

### 3. 人事

首版每天只选择三件真正重要、来源可核验的事件。每个事件先回答：发生了什么、何时发生、在哪里发生、依据是什么、哪些信息仍不确定。

### 4. 象理

事实确认后，墨观才调用经过分期准入的古代文献，分析显隐、动静、扩张、收缩、承载、阻断、转折和失衡。每项解释必须附原典、篇章、原文、成书与传世年代、时代层级、材料功能和现代转译。

### 5. 验期

系统把部分分析转成有明确对象和时间窗口的情景推演，保存现实证据、古典分析链、触发条件、失效条件及到期结算结果。

## 二级能力：事件研判

用户可以提交一张截图、一段文字或一个公开链接。墨观先识别事件对象、时间、地点、主体和核心主张，再寻找原始出处与交叉信源，区分已经确认的事实、来源观点、未经证实的说法和系统推测。

完成事实核验后，系统才把该事件放回当日星象、历法、天气、相关市场与历史背景中，并调用经过准入的古籍规则进行分析。输出固定包含：

1. 事件摘要与提交材料识别结果；
2. 来源、时间校准、交叉证据与事实置信度；
3. 当日天地和现实环境中的相关背景；
4. 原典、现代释义、映射过程、异说与反证；
5. 若干可能情景、触发条件、失效条件和后续观测点；
6. 明确标注的未知事项与分析置信度。

事件研判不回答“这件事能不能成”“结果吉不吉利”等问事型问题，不根据提交时间机械起卦，也不把用户提供的截图或链接默认视为真实。

# 四、可信度框架

墨观的核心不是“看起来很准”，而是让用户始终知道哪些是事实、哪些是古人的观点、哪些是墨观的解释、哪些仍在等待验证。

## 五层信息

1. **天文与天气事实**：由现代星历、观测、再分析或预报数据直接支持；
2. **事件事实**：由公开来源和新闻原始信息链支持；
3. **原典观点**：古籍在特定历史语境中的原文与含义；
4. **墨观解释**：古典概念映射到现代事件的版本化分析；
5. **预测情景**：尚未发生、等待未来事实结算的判断。

事实置信度、古典映射置信度和预测置信度必须分别计算，不能相互替代。

## 三条审计链

### 事实链

来源 → 时间 → 地点 → 主张 → 支持证据 → 反向证据 → 未知事项

### 古典分析链

事件功能特征 → 原典片段 → 历史语义 → 允许范围 → 五行或八卦映射 → 异说与反证

### 预测链

判断对象 → 时间窗口 → 情景 → 触发条件 → 失效条件 → 结算来源 → 到期复盘

## 模型边界

语言模型可以帮助检索、整理、生成候选映射和表达分析，但不能：

- 创造不存在的古籍原文；
- 臆测天体位置、天气数值或新闻事实；
- 自行发明五行对应；
- 用流畅文字掩盖来源缺失；
- 绕过人工审查直接发布重要结论。

# 五、古代天文与思想知识库

墨观的长期知识底座扩展至先秦、两汉、隋唐和两宋。知识库不再设置公元 220 年的单一截止线，而采用“时代分层、功能分型、异说并存”的准入方式。唐宋材料可以参与分析，但必须保留其自身时代背景，不能伪装成先秦或汉代原义。

## 四个历史层级

| 层级 | 主要价值 | 使用边界 |
|---|---|---|
| 理论源头层｜先秦—两汉 | 天人关系、阴阳五行、八卦、时序与早期星官体系 | 负责说明概念源流，不因年代早而自动获得更高事实权重 |
| 制度集成层｜魏晋—隋唐 | 天文志、占候文献、历法制度、文献汇编与跨文化吸收 | 必须区分本土传统、印度及中亚输入，以及后世整理成分 |
| 观测精化层｜两宋 | 星图、客星与彗星记录、历法修订、仪器和官署方法 | 观测记录可作为历史数据，术数解释仍须单独标注 |
| 现代校验层｜当代 | 现代星历、天气、历史研究与文本校勘 | 只用于确认事实、版本和解释边界，不为古代因果背书 |

## 三层知识结构

| 层级 | 保存内容 | 能否参与公开判断 |
|---|---|---|
| 全文文献层 | 完整文本、目录、篇章、底本、版本差异与许可记录 | 可以检索和阅读，不能自动形成结论 |
| 校核片段层 | 原文片段、上下文、断句、异文、释义与双源比对 | 可被研究者引用，仍需审核状态 |
| 可执行规则层 | 审核通过的规则、允许范围、禁止外推、异说与反证 | 只有达到发布门槛后才能参与分析 |

首批知识库按三批建设：

1. **源头批**：《易传》《尚书·洪范》《吕氏春秋》《淮南子》《史记·天官书》和《论衡》。其中《论衡》承担强制反证作用；
2. **唐代集成批**：《晋书·天文志》《隋书·天文志》《乙巳占》《开元占经》《大衍历》相关材料，以及能够确认来源和译传关系的七曜、宿曜文献；
3. **宋代观测批**：《新仪象法要》、宋代星图与客星记录、《梦溪笔谈》天文历法条目，以及《宋史·天文志》中可追溯至宋代原始记录的材料。

《宋史》成书于元代，不能直接标记为宋代成书文献；系统必须同时记录“事件发生年代、原始记录年代、现存文本编纂年代和当前底本年代”。

## 材料功能标签

每一条文献片段必须标记其主要功能：理论、占候、观测、历法、仪器、制度、史例或后世评论。观测记录不能自动生成占候结论，占候文本也不能被当作现代天文事实。

## 五行映射原则

五行在墨观中描述功能、关系、阶段和变化，不是给现代实体贴永久标签。

- 木可以描述生发、扩展与疏通，但科技或企业不自动属木；
- 火可以描述显现、加速与剧烈冲突，但战争或舆论不自动属火；
- 土可以描述承载、统合与稳定，但国家或政府不自动属土；
- 金可以描述收敛、切割、规范与执行，但金融或武器不自动属金；
- 水可以描述流动、渗透、储藏与运输，但资本、信息或航运不自动属水。

每个非零五行权重都必须同时具备现实事件特征、已准入原典规则和完整推导说明。

# 六、用户与使用场景

## 首批用户

- 关心世界局势、历史、中国哲学和天文天气的世界观察者；
- 历史、国际问题、财经与传统文化内容创作者；
- 海外华人、英文 I Ching 和中国思想爱好者；
- 天文馆、博物馆、高校和数字人文机构。

## 典型使用场景

- 每天用五分钟查看今日天空、全球天气和三件重要事件；
- 点击一个事件，阅读事实来源、原典分析和反证材料；
- 沿时间轴回看某次天象、历史事件与古典解释；
- 订阅一个议题，跟踪情景预测和到期复盘；
- 将双语原典、图表或时间线用于内容创作、展览与教学。

首版不是为金融机构、政府或军事客户设计。未来如发展专业事实产品，必须与古典解释层分开命名、分开验证、分开销售。

# 七、商业模式

墨观不销售“更吉利的结论”，而销售更完整的知识、历史、工具和表达能力。

- **免费层**：今日天象、全球天气、三件事件和简短分析；
- **个人会员**：完整原典链、历史回看、自定义议题、一定额度的事件研判、情景推演和预测账本；
- **创作者版**：图表导出、双语引用、嵌入组件和商业发布授权；
- **数字专题**：节气、年度、重要天象和历史事件报告；
- **机构授权**：展览、课程、教学包和文化天文可视化。

商业模式不得依赖战争、灾害或个人恐惧，不提供付费改运、投资指令或军事行动建议。

# 八、MVP

MVP 只验证一个问题：

> 用户是否愿意从中国古代星空进入地球，在同一条体验中查看真实天气、三件世界事件及先秦至宋代的分层分析，并愿意第二天再次回来？

## 固定日期 P0

首版只完成：

1. 一个固定日期和统一数据截止时间；
2. 一个真实中国星空视图；
3. 一个全球天气图层；
4. 三件人工确认的公共事件；
5. 至少三条带原文和篇章的古典规则；
6. 一条有期限、有触发条件和失效条件的情景推演；
7. 一个受控的事件研判入口，接受截图、文字或公开链接，并输出事实核验与结构化分析；
8. 一页公开的方法、来源与限制说明。

## 暂不进入 P0

- 个人命盘、随机起卦和运势；
- 全球新闻自动抓取；
- 无限制开放的事件提交与自动发布；
- 多套后世术数并行排盘；
- 复杂 GIS、全球 AIS 与实时敏感轨迹；
- 自动交易、投资或军事建议；
- 支付、社区和复杂账户系统。

# 九、发展路线

## 阶段 0｜世界模型设定

冻结文献准入、五行映射、全文知识库、数据模型和发布边界。

## 阶段 1｜固定日期 P0

验证“星空—地球—事件—原典—预测”的完整体验。

## 阶段 2｜连续 30 天 P1

每天更新天象、天气和三件事件，由系统检索规则、人工确认分析，并结算到期预测。

## 阶段 3｜优先专题

根据真实用户行为，只选择金融、冲突、气候、科技或航运中的一个专题深化。

## 阶段 4｜会员与创作者版

上线历史回看、提醒、导出、专题报告和预测账本，验证付费与留存。

## 阶段 5｜英文版

通过双语原典、概念解释和本地天空，面向海外华人与全球中国思想爱好者。

## 阶段 6｜机构与教育

形成可授权给天文馆、博物馆、高校和数字人文机构的展览与教学产品。

# 十、不可动摇的产品边界

1. 文献范围扩展至宋代结束，但每条材料必须标注时代、功能、底本和传承关系；
2. 唐宋材料不得倒置为先秦—两汉原义，不同历史体系不得无标记混用；
3. 观测、历法、仪器、制度与占候材料必须分型保存和调用；
4. 现代天文、天气和事件事实不由古典理论或模型修改；
5. 不把天象与战争、市场、政治或灾害写成已获科学证实的因果关系；
6. 不采集个人出生信息，不提供个人吉凶、财运或健康判断；
7. 不使用随机起卦作为公共事件结论来源；
8. 不把事件提交入口包装成问事、占算或个人成败判断；
9. 不把用户提交的截图、文字或链接默认视为真实；
10. 不把国家、民族、宗教或个人永久指定为某一行；
11. 每项公开分析同时展示支持证据、反向证据和未知事项；
12. 每项预测必须有期限、判定标准、触发条件和失效条件；
13. 到期结果和历史修订不可静默删除；
14. 不输出投资、交易、军事行动、医疗或安全关键建议。

# 十一、墨观最终要成为的产品

墨观不是用古代词汇重新包装新闻，也不是用视觉效果制造神秘感。

它最终要成为一套有自身文化根基、又能接受现代事实检验的世界观察系统：天空是真实计算的，天气是可追溯的，事件是经过核验的，古籍是可以回到原文的，解释是允许争论的，预测是必须复盘的。

> 看见天时，理解地气，观察人事；以古典照见变化，以事实校验判断。
